# Asciinema Explainer Walkthroughs & Terminal Demos

This skill provides instructions, synchronous Python PTY recorder scripts, ANSI banner templates, and 2-tab HTML web player templates for producing production-grade, deterministic terminal recordings (`.cast` files) and interactive explainer walkthroughs.

- "record a terminal demo"
- "build an explainer walkthrough"
